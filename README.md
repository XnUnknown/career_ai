# CareerCompass

AI-Based Career Recommendation System — Next.js + Ollama.

## Status

🚧 Initial UI scaffold (no LLM yet). The `/api/chat` route currently echoes back a placeholder response. Ollama integration is the next milestone.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000 and click **Start Chat**.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Ollama (planned)
- Web search & fetch tools (planned)

See `../PLAN.md` and `../PROJECT_DOC.md` for the full plan.
